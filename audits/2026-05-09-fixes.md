# cw-middleware — 2026-05-09 Audit Fix Summary

> Companion to [`2026-05-09-internal-audit.md`](./2026-05-09-internal-audit.md) and [`2026-05-09-fix-plan.md`](./2026-05-09-fix-plan.md).
> Branch: `fix/audit-2026-05-09`. Maps every audit finding to the commit that addresses it.

## Architectural Decisions Made During Remediation

1. **Mock family deleted** — replaced by real ECDSA + BLS implementations.
2. **ECDSA / BLS implementations** — POA-shape (operator self-registration with owner-managed weights), single-contract stake-registry-style folded into the service-manager.
3. **Owner / Admin role split** — both ECDSA and BLS service-managers separate the operator-set role (OWNER) from the operational-config role (ADMIN). Mirror keeps the existing two-contract split (stake-registry has OWNER, service-manager has ADMIN).
4. **Pause mechanism** — ECDSA + BLS service-managers expose owner-only Pause/Unpause; validation queries return Paused error and weight-mutating writes reject when set.
5. **Two-step ownership transfer** — ECDSA + BLS use TransferOwnership/AcceptOwnership and SetAdmin/AcceptAdmin (two-step). Mirror uses single-step TransferOwnership/SetAdmin because the typical handoff target is a contract address that can't sign an "accept" message.
6. **Snapshot quorum threshold** — historical envelopes are evaluated against the threshold in force at their `reference_block` (not the current threshold).
7. **No `migrate` entrypoints** — explicit choice to defer migration story until the first state-shape change forces a designed surface.
8. **`#[serde(untagged)]` Wavs wrapper** — preserved per upstream `wavs-types` protocol convention. M-5 reframed: explicit JSON keys per variant make practical misdispatch unlikely; the original concern is mitigated by C-3 auth gating.
